3. Static single-mark ownership: new reproducible Unicode result

A fixed OnceLock<[CellExtra;112]> holds U+0300..U+036F immutable mark-only
records. CellExtraRef is a private-field NonNull wrapper; low address mask 1
tags static content. A compile-time alignment check reserves it. map_addr
preserves provenance; tags are cleared before dereference. Untagged pointers
own exactly one Arc strong reference. Their Clone/Drop increment/decrement
that count. Pooled handles need no refcount operations. Option remains one
word and the existing 24-byte Cell cap is preserved.

Mutation copies static content into owned Arc first. Owned mutation reclaims
its count with from_raw, applies Arc::make_mut, and restores raw ownership
through a write-back guard before producing the mutable reference. Weak
reference dissociation is covered. Serde and equality are content-based;
deserialization yields owned content. Other marks retain the bounded Arc
single-mark cache. Styles, hyperlinks and nine-mark caps remain unchanged.

This is unsafe ownership code and changes the public Cell.extra field type
from Option<Arc<CellExtra>> to Option<CellExtraRef>. It is not Arc-API
compatible; From<Arc<CellExtra>> transfers ownership. That compatibility
cost is explicit and remains archived, not shipped. No Unicode normalization
or input-sized pool was introduced.
