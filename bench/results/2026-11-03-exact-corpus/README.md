# Exact terminal corpus bridge — iteration 33, 2026-11-03

## Retained change, not a runtime optimization

Add `bench/export-tput-corpus.py` and opt-in `GLASS_BENCH_CORPUS` loading in
the existing `#[cfg(test)]` speed module. The exporter executes the existing
trusted `tput.py` generator AST, not a rewritten RNG, and writes fixed files to
a new directory with a completion manifest last. The loader rejects missing or
wrong-shaped payloads, geometry mismatch, empty/oversized files and rescaling.
**The Rust loader does not authenticate corpus hashes.** An external runner
must check manifest and payload SHA256 before/after use. The default generated
benchmark path and all production engine/parser code are unchanged.

The headless generator's xorshift and its extra ASCII-LF workload consume a
different random sequence from Python `random.Random(7)`. A non-timed export of
both generators now establishes actual byte identity/difference rather than
assuming the same workload names mean the same inputs:

| workload | Python minus generated bytes | identical SHA256? |
|---|---:|---|
| ASCII | 0 | no |
| Unicode | -12 | no |
| truecolor | -2,382 | no |
| cursor-motion | -400 | no |
| scroll-region | 0 | no |
| TUI | 0 | yes |

An independent `runpy` execution of **unchanged** `bench/tput.py`, with terminal
size/waiting mocked and stopped immediately before its first terminal-mode
call, matches all six exported payloads byte-for-byte. It does not use AST
extraction or copy the generator. No real terminal I/O happens in that check.

## Frozen diagnostic

One release test ELF; 24 sequential sessions / 12 alternating generated/exact
pairs, scale 1, 39x154, reads 4095, five internal repetitions. Protocol frozen
before measurements, no pilot/retries/exclusions/optional stopping. Rates are
existing best-of-five outputs, not five independent observations per session.

| workload | exact/generated median CPU rate | median wall rate | favorable pairs | Holm p |
|---|---:|---:|---:|---:|
| ASCII | 1.000834 | 1.000997 | 6/12 | 1.0 |
| Unicode | 1.021723 | 1.021765 | 9/12 | 0.875977 |
| truecolor | 1.004052 | 1.003942 | 6/12 | 1.0 |
| cursor-motion | 1.001558 | 1.001561 | 7/12 | 1.0 |
| scroll-region | 1.007221 | 1.007578 | 8/12 | 1.0 |
| TUI | 0.999341 | 0.999177 | 4/12 | 1.0 |

**No significant corpus effect established.** The Unicode median difference
is not an optimization gain, not a correction factor for past candidates, and
not a revision of the terminal/Ghostty gap. Its pair range is .980916–1.057077.
Identical TUI bytes still range .982714–1.027740. Sequential balancing on a
shared machine does not establish independent fair signs. Generated setup
allocates/builds payloads while exact setup reads files; both are outside the
timer, but allocator/cache/setup carryover remains a confound. This experiment
cannot uniquely attribute a throughput difference to payload bytes. CPU and
wall best passes are selected independently by the existing harness.

## Reproduce / use the bridge

Read-only checkpoint, no build or timing:

```sh
python3 -B bench/results/2026-11-03-exact-corpus/verify.py
python3 -B bench/replay-evidence-index.py \
  bench/results/2026-11-03-exact-corpus/final-frozen-index.json
```

New corpus, not overwriting retained evidence:

```sh
python3 -B bench/export-tput-corpus.py /tmp/new-glass-tput-corpus
# Check SHA256 of each payload against the generated manifest externally.
GLASS_BENCH_CORPUS=/tmp/new-glass-tput-corpus GLASS_BENCH_SCALE=1 \
GLASS_BENCH_ONLY=ascii,unicode,truecolor,cursor_motion,scroll_region,tui_frames \
cargo test -p glass-term --release speed::speed -- --ignored --exact --nocapture
```

Retained capture scripts are single-use and intentionally refuse overwrite.
Archived `.bin.xz` files need decompression into a fresh directory to rerun
an engine session. Historical data analysis uses archives directly and never
reruns timings. `verify.py` also works if the original `/tmp` diagnostic ELF
has disappeared; it verifies the retained ELF instead. A conflicting existing
live ELF fails closed.
