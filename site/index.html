glass

A GPU terminal that takes in every graphics dialect and draws it as layers, 3D and video.

A program runs in a pseudo-terminal. glass takes in the graphics dialects programs already speak, and its own, and expands them into one picture store drawn above and below the text: pictures, glows, particles, lit 3D scenes, glTF models with their animations, and video.

Open intake

It takes in what programs already say.

No dialect is the reference one. Each is an adapter that turns its own escape sequences into one shared description of what to show.

APC graphicsESC _ G

Every transmission medium, chunking, compression, z-index above and below the text, source rectangles, Unicode placeholders, relative placements, animation.

SixelDCS … q

Sixel pictures, with raster attributes and aspect.

Inline imagesOSC 1337

File= and the multipart form: PNG, JPEG, GIF, TIFF, WebP, BMP, ICO, TGA, PNM.

KeyboardCSI u

The progressive key flags, alongside legacy key bytes.

HyperlinksOSC 8

Links, opened with Ctrl+click.

tmux passthroughDCS tmux;

Wrapped sequences are unwrapped and taken in.

glass's own dialectESC _ glass;…

Layers and groups, glows, rings and lines, particles, lit primitives, 3D scenes with chrome and liquid materials, glTF 2.0 models with skinning and animations, tweens glass plays itself, video and charts. Plain APC strings: a shell script can do it with printf, over ssh, and other terminals ignore it.

Pictures follow the text: they move with scroll regions and the alternate screen and keep their place through reflow on resize. Text written over an in-cell picture hides only the cells it covers.

Try it

Escape codes, from a shell.

Paste these into a glass window. The whole dialect is in docs/GLASS_DIALECT.md.

glass
# a soft violet glow under this line and the two below it
printf '\033_glass;layer;id=1;k=glow;c=8844ccff;add=1;at=0,0,80,3\033\\'

# warm sparks rising from the rows below
printf '\033_glass;layer;id=2;k=particles;c=ffd080;n=120;size=2;life=3;rise=30;sway=12;at=0,1,80,4\033\\'

# a glowing ring with a line across it, pinned to the window
printf '\033_glass;layer;id=5;k=ring;c=40b0ff;lw=2;glow=7;add=1;px=400,200,240,240\033\\'
printf '\033_glass;layer;id=6;k=line;c=ff60c0;lw=1.5;glow=4;add=1;a=0.785;px=370,319,300,2\033\\'

# the ring breathes orange and back, for ever: glass plays the tween itself
printf '\033_glass;tween;layer=5;c=ff8800;dur=1.5;ease=sine-in-out;repeat=forever;yoyo=1\033\\'

# take it all down
printf '\033_glass;remove;all=1\033\\'

Install

One line on Linux.

curl -fsSL https://github.com/newjordan/glass/releases/latest/download/install.sh | sh

It installs into ~/.local/glass and links ~/.local/bin/glass, with the desktop entry and icons. --uninstall takes it out again.

Arch Linux (AUR)

yay -S glass-term-bin

The release binary; glass-term builds it from source.

From source

git clone https://github.com/newjordan/glass
cd glass
cargo build --release -p glass-term

Run

glass
glass -e htop

Your shell, or a command. Settings live in ~/.config/glass/glass.conf, written on the first launch: every key.

glass needs a Wayland or X11 desktop with a Vulkan driver, fontconfig, and wl-clipboard or xclip. Building needs Rust 1.95 or newer.
